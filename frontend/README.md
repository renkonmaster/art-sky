# frontend

ギャラリーの画面。React + Vite。

## 動かし方

```sh
pnpm install
cd frontend
pnpm dev        # http://127.0.0.1:5173 を開く
```

バックエンドがなくても、開発サーバーに組み込んだモックで動く。

| コマンド | 内容 |
|---|---|
| `pnpm dev` | モックで起動する |
| `BACKEND_URL=http://127.0.0.1:3000 pnpm dev` | 本物のバックエンドに転送して起動する |
| `pnpm test` | モックのテスト |
| `pnpm e2e` | 実際のブラウザ（Chromium）で画面を確認する。`pnpm e2e <フォルダ>` でスクリーンショットも保存する |
| `pnpm typecheck` | 型チェック |

`pnpm e2e` が Chromium を見つけられないときは `pnpm exec playwright install chromium` を実行する。

## 画面

| パス | 画面 | ログイン |
|---|---|---|
| `/` | 全体ギャラリー（参加者ごとの最新作品） | 不要 |
| `/u/:actor` | 個人ギャラリー（`actor` は DID かハンドル名） | 不要 |
| `/u/:did/:rkey` | 作品詳細 | 不要 |
| `/u/:did/:rkey/card` | 名刺（自分の作品の絵を名刺の形にして PNG で保存する） | 必要 |
| `/login` | ログイン（ハンドル名を入力して Bluesky の認可へ進む） | ― |
| `/register` | 初回登録（外部 AI に送る内容への同意、最初の作品の生成） | 必要 |
| `/manage` | 管理（生成停止と掲載の設定、生成の履歴と再試行、ログアウト） | 必要 |

ログインが必要な画面を未ログインで開くと `/login` へ送り、ログイン後に元の画面へ戻す。
初回登録がまだの人は `/register` へ送る。

## ギャラリーの配置

全体ギャラリーと個人ギャラリーは、右上のボタンで配置を切り替えられる。選んだ配置はブラウザに保存する。

| 配置 | 内容 |
|---|---|
| 1 枚ずつ（既定） | 作品を 1 枚ずつ大きく縦に並べ、ページをふつうにスクロールして見る（スナップで止めたりしない）。右端の上下ボタンと `j` / `k` キーで前後の作品へなめらかに移る。再生ボタンを押すと 7 秒ごとに自動で次へ進む |
| タイル | 高さの違うタイルを、画面幅に合わせた列数で敷き詰める |

実装は [Feed.tsx](src/components/Feed.tsx)。

## 名刺の書き出し

自分の作品の詳細画面に「この作品を名刺にする」ボタンが出る。作品の絵に名前、ハンドル名、題名、生成日を添えた名刺を作り、PNG で保存できる（[CardPage.tsx](src/pages/CardPage.tsx)、[card.ts](src/lib/card.ts)）。

- 大きさは日本の名刺（91 × 55 mm）の比率で、横向き 1820 × 1100 画素、縦向き 1100 × 1820 画素。
- 向き（横・縦）と色（黒・白）を選べる。差し色は絵の平均の色から決める。
- 絵は、見えない iframe で作品を 1600 画素で描き直して受け取る（[useArtworkSnapshot.tsx](src/components/useArtworkSnapshot.tsx)）。
- アニメーション作品は、開始から 1.5 秒の時点の絵を使う。時刻を 1 フレーム 1/60 秒として進めるので、何度作っても同じ絵になる。
- 名刺にできるのは自分の作品だけ。

## 作品の描画

作品は画像ではなく、レコードに入っている描画関数をその場で実行して表示する（[ArtworkFrame.tsx](src/components/ArtworkFrame.tsx)）。

- コードは `packages/renderer` が作る HTML を、`sandbox="allow-scripts"` の iframe に入れて動かす。
  iframe の中ではさらに Web Worker で実行するので、無限ループするコードでも画面は固まらず、5 秒で打ち切る。
- 画面から 1 画面ぶん以内に近づいた作品だけ描画する。素早くスクロールして通り過ぎるだけの作品は描き始めない。
- 静止画は描き終えたら PNG に置き換えて iframe を片づける。アニメーションは画面から外れたら止める。

## モック

[mock/](mock/) にある。`docs/api.md` の API をすべてメモリ上で再現する。

- 参加者 8 人と作品 24 件が最初から入っている（すべて架空）。作品のコードは `mock/styles/*.js`。
- `/oauth/login?handle=<ハンドル名>` を開くと、そのハンドル名でログインした状態になる。
- 登録すると、約 7 秒で生成ジョブが完了して最初の作品ができる。
- このサイトに投稿機能はない（本物のバックエンドは Bluesky 上の投稿を見つけて作品を作る）。
  モックでは、次のコマンドで「Bluesky に投稿があった」ことにできる。`"fail": true` を足すと生成が失敗する。

  ```sh
  curl -X POST http://127.0.0.1:5173/__mock/post -H 'content-type: application/json' -d '{"handle":"mio.example.com"}'
  ```
- 状態はメモリにあるだけなので、開発サーバーを再起動すると最初に戻る。
